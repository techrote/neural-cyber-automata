# Conditional Jolt per-part graph

This record supports [T-110 / #20](https://github.com/techrote/neural-cyber-automata/issues/20).
The commissioned task is one Jolt `directed_hop` behaviour with the three-part
star in [the immutable declaration](../../configs/cellular/jolt-three-part-hop-v1.json).
Its canonical configuration SHA-256 is
`e5a66f5a830b9e097a5bbb9647ade4bea42c82e26fb5718273b5bae2b992de5d`.
This declaration preceded implementation, training and inspection of any T-110
scenario outcome. No physical game screen has run at this source preparation
checkpoint; a final experiment appendix will identify its frozen learner source
and actual outcomes. Unit checks alone provide no game-efficacy result.

Accepted prerequisite evidence is T-101/T-102 and T-104, the latter merged at
`b5f665244d117fe55de7a4bd65721835684646f8`. The candidate uses their strict
contracts, pinned host adapter and per-base-tick capture API, plus the accepted
authored controller. It does not depend on unfinished learning, asynchronous
decision, export or morphology implementations.

## Topology and information contract

| Owner | Permitted local inputs | Memory and output |
|---|---|---|
| Root `impact_core` | Own part pose, velocity, angular velocity, mass and size; actor support, energy, cooldown, ground/ceiling rays and availability; explicit caller goal and previous actor request | 16 private floats; eight-float message; sole six-channel action readout |
| Left `rebound_pad_-1` | Its own part motion, mass and size; the same explicit goal/request context; root-only sensor slots unavailable | 16 private floats and eight-float message |
| Right `rebound_pad_1` | Its own part motion, mass and size; the same explicit goal/request context; root-only sensor slots unavailable | 16 private floats and eight-float message |

The star has only root–left and root–right edges. One synchronous round per six
completed 60 Hz host ticks gives one-hop instantaneous reach. A pad-to-pad
influence needs two successive decisions through the root. No hidden global
pooling, reward, evaluator state, other actor or cell patch enters the features.
The common goal is supplied explicitly by the caller; it is not extracted from
an evaluator.

Both learned variants run the same three-node population and 2,878 parameters.
The no-message control disables cross-node messages while retaining an active
self-message branch. The authored controller has the same permitted actor
information budget and elects to use root feedback only. Strict local feature
and sensor-location matching is between graph and no-message. The authored
comparison supplies the gameplay reference gate; it cannot by itself establish
a causal benefit from communication. All three use the same bounded six-channel
mapping, aimed-hop direction and support/known-cooldown/rising-edge primary
gate. Host assistance, compliant joints, Rapier and native material ownership
remain common. Tool, mount, reel and direct material-write channels are absent.
Direct creation/destruction/conversion request budgets are zero in all three
methods. The pinned host's
[Jolt pulse implementation](https://github.com/techrote/cybersand/blob/f2e34cf9b6fbaa5d9dedf9aa2cbc721a87472497/godot/scripts/physical_actor_rig.gd)
invokes the physical jump. Passive contacts, body masks and material evolution
stay with the native host and are not controller-issued cell writes.

Queued messages retain their original source ticks, expire at age 12 ticks
exclusively, and have a hard capacity of 16. Missing messages are not held.
Actor incarnation, profile, goal and control/source/mount generation changes
clear recurrence and the corresponding queues. Cancellation retires the old
invocation; a new control generation cannot resume its old goal. A physical
part/joint topology mismatch disarms this fixed candidate and is refused.

## Fixed experiment and evidence limits

The training set is eight new authored episodes from four declared families;
unsuccessful trajectories remain labelled and eligible autonomous rows remain
available. Each of three seeds trains both models for 30 fixed BC epochs with
the same initialization and shuffle seed. Padding advances neither loss nor
private memory. The final epoch is selected in advance. Corrections, privileged
teachers and likelihood-free samples cannot become PPO actor likelihood data.

All six final checkpoint hashes must be written before opening the holdout.
The separate tuning family is diagnostic only. Two holdout families use paired
host seeds under normal, one-decision delay, 25% loss, right-pad communication
partition and tick-60 private-memory reset. Communication faults do not mutate
physical joints. The reset keeps actual body motion, the caller goal and the
external deadline. Physical topology mutation and morphology transfer remain
unmeasured; software rejection of an unsupported topology is not such a result.

The declared plan uses at most 3,570 game decisions with a hard 4,000-decision /
900-second CPU ceiling and one Torch thread. There is no automatic extension,
checkpoint selection or post-holdout training. The report applies the declared
paired three-policy-seed uncertainty calculation and all success, timing,
integrity, style, inference and stress gates. Failure means no-go under this
screen; an incomplete matrix means inconclusive. Owner feel remains unassessed.

Two task definitions also occur in the independent T-105 suites. Its six final
checkpoints froze at `2026-10-19T01:37:45.214103+00:00` before any T-110 outcome
was available. No T-105 dataset, checkpoint or outcome was used to select or
tune this graph declaration.

## Source preparation checks

The optional learning environment ran `python -m unittest discover -s tests -p
test_cellular.py -v`: 33 checks passed and the single actual-host check was
skipped because no host was configured for this preparation run. These checks
cover local sensor assignment, one-hop and successive-round causal reach,
active equal-size no-message recurrence, exclusive message expiry, deterministic
loss, partition, lifecycle fences, duplicate ticks, topology refusal, padding,
fixed-seed synthetic BC, checkpoint/config integrity and conservative missing/
duplicated-outcome handling. The no-Torch core environment passed 20 checks and
skipped 14 optional learning/host checks. A skipped lane is unmeasured.

The first test draft checked recurrent-weight gradients on a zero initial state
after only one update; that test could not exercise the recurrent weight. It was
corrected to use two updates. A subsequent test-file insertion indentation error
was corrected before the passing run. Neither development failure involved the
actual host or changed the experiment declaration.
