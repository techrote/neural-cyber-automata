## Failed attempts and review corrections

An initial probe passed an unsupported `ticks` keyword to the environment's
ordinary `step` helper and stopped with a Python argument error. The corrected
calls use the configured six-tick repeat; the argument failure is not physical
evidence. Early raw usable probes also encountered actual source-identity or
clearance refusals. Later explicit no-change cases remain no-change outcomes,
rather than being relabelled as successful damage.

Independent peer review found that a transport/recording exception could escape
an accepted task without cancelling armed intent. The task runner now attempts
runtime and real-owner cancellation while preserving the original exception.
Its regression arms primary, injects a step error and a cleanup error, and verifies
one step, one owner-cancel attempt and no release action.

The peer also found that report-time timeout could discard a valid native effect
from an earlier tick in the same repeat. The runtime now judges the first
unambiguous effect by its original event time: an effect at or before the skill
deadline can complete locally, while a later effect is retained and the skill
times out. Exact on-time/late tests cover this inclusive effect-deadline rule.
This task deadline is distinct from the host wire lease's exclusive expiry.
The peer re-reviewed those changed blocks and found no further blocker.

### Integration correction for connection generation

Subsequent ownership-router review reproduced a cross-interface defect: after
detachment made the connection generation one, control-only cancellation reset
that generation to zero. A legitimate takeover then conflicted with the router's
unchanged-equipment invariant. Cancellation now preserves the observed connection
history while advancing the independent actor control fence. Only a changed
physical actor/object lifetime resets the connection count. The new unit and
actual-host regressions cover release, cancellation, stale old-control refusal,
regrip and another cancellation. Their connection counts are zero, one, one,
two and two, while old actor control identities remain invalid.
Independent peer review of the final `mount_ref` block confirmed that only
control-generation changes preserve this history and that the complete actor
identity still fences old requests; no additional blocker was found there.

## Explicit limits

All success here is a declared local predicate. There is no privileged global
target-state or reward oracle in the skill controller and no evaluator-success
claim. `local_effect_consumed_no_change` explicitly means no changed cells; it
does not establish target damage, excavation or objective completion.

Cancellation revokes future intent, charge and queued owner input. Existing
recoil, attachment and applied material changes remain owned by the world.
Native Fire/material continuation was exercised; a separately autonomous
projectile or projectile timer was not available as a qualified example and
is not claimed. Owner cancellation after a broken connection is best effort;
transport/lifetime fences continue to apply.

The selected articulated body is an authored own held part, not an arbitrary
foreign object. Detached objects beyond range can remain unreachable. Independent
object replacement, exhaustive usable combinations, Windows execution, desktop
pacing and owner feel remain unmeasured. The model label is an interface case,
not a live model planning result. Learned skill replacement and comparative
training quality remain outside this authored implementation.
