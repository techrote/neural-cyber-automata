# Structural JSON schemas

These JSON Schema 2020-12 files describe the implemented dataclass field names,
types, exact tuple dimensions, required fields and literal versions. They are
generated by `Record.json_schema()` for the class named in each schema's title.

The Python decoder is the semantic authority. It additionally rejects duplicate
JSON object keys, nonfinite numbers, oversized messages, invalid topology,
inconsistent masks, out-of-range controls, mismatched profile hashes and invalid
lifecycle/clock relationships. Passing a standalone structural schema check is
insufficient to admit a command or qualify a run.

| Schema | Python type | Scope |
|---|---|---|
| [gameplay-profile-v1.schema.json](gameplay-profile-v1.schema.json) | `GameplayProfile` | Rig, sensor, channel, assistance and capability manifest |
| [observation-v1.schema.json](observation-v1.schema.json) | `Observation` | Copied permitted observation and unavailable-value mask |
| [command-v1.schema.json](command-v1.schema.json) | `Command` | Experiment request record with lifecycle identity |
| [act003-command-v1.schema.json](act003-command-v1.schema.json) | `LegacyCommand` | Preserved ACT003 host packet |
| [act004-wire-values-v2.schema.json](act004-wire-values-v2.schema.json) | `WireAction` | Bounded ACT004 action values; no host envelope |
| [run-manifest-v1.schema.json](run-manifest-v1.schema.json) | `RunManifest` | Immutable experiment provenance |

Do not interpret the experiment record's schema version as a host protocol
version. V1 ACT003, v2 ACT004 and the research records have separate types.
